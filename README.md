# 🎬 Simulated HD Video Player UI + RideFiles Content Locker

একটি নিখুঁত ও হাই-কনভার্টিং সিপিএ ল্যান্ডিং পেজ, যেখানে **কোনো ভিডিও ফাইলের প্রয়োজন নেই**! এটি ব্রাউজারে একটি আসল ফুল এইচডি ভিডিও প্লেয়ারের মতো দেখাবে এবং স্বয়ংক্রিয়ভাবে বা প্লে বাটনে ক্লিক করলে কন্টেন্ট লকার ওপেন হবে।

---

## 🚀 এটি কীভাবে কাজ করে?

1. **কোনো ভিডিও আপলোডের ঝামেলা নেই:**
   - কোনো ভারী `.mp4` বা ভিডিও ফাইল ছাড়াই পেজটি একটি রিয়েল স্ট্রিমিং প্লেয়ার (সিনেমাটিক পোস্টার ব্যাকড্রপ, লাইভ টাইমলাইন, বাফারিং বার, কোয়ালিটি ব্যাজ) হিসেবে কাজ করে।
   
2. **প্লে বাটনে ক্লিক করলে লকার অ্যাকশন:**
   - ভিজিটর যখন সেন্ট্রাল প্লে বাটন বা ফুটার প্লে বাটনে ক্লিক করবে, তখন ১.২ সেকেন্ড বড় গ্লোয়িং লোডার ("Buffering HD Stream...") ঘুরবে।
   - ঠিক এরপরই সরাসরি আপনার **RideFiles কন্টেন্ট লকার** ওপেন হবে।

3. **অটো-লকার টাইমার (Auto-Popup):**
   - লিংক ভিজিট করার ঠিক **৫ সেকেন্ড পর** পেছনের ভিডিও ব্যাকড্রপটি ব্লার হয়ে লাইভ কন্টেন্ট লকার পপআপটি ভেসে উঠবে।
   - সময় পরিবর্তন করতে [`assets/js/main.js`](file:///c:/Users/robiu/OneDrive/Desktop/Demo/assets/js/main.js)-এর শুরুতে `OFFER_DELAY_SECONDS = 5;` পরিবর্তন করতে পারেন।

4. **মডার্ন ডার্ক গ্লাস লকার স্টাইল:**
   - RideFiles-এর পুরনো সাদা বক্সটি স্বয়ংক্রিয়ভাবে একটি আধুনিক ডার্ক গ্লাস-মরফিজম কার্ডে রূপান্তরিত হবে, যাতে অফারগুলো আকর্ষণীয় দেখায়।

## ⌨️ শর্টকাট
- **`Space` বা `K`** : প্লে সিমুলেশন চালিয়ে লকার ওপেন করা
- **`L`** : সরাসরি লকার টগল করা
- **`F`** : ফুলস্ক্রিন
- **`M`** : মিউট / আনমিউট
